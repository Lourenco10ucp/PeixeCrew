# PeixeCrew

Planeador de caça submarina e apanha para a costa portuguesa: estado do mar (vários modelos e IPMA), marés (previsão astronómica), regras oficiais (DGRM), identificação de espécies, locais partilháveis entre amigos e diário que aprende.

Abra no telemóvel e instale («Instalar aplicação» no Android, «Adicionar ao ecrã principal» no iPhone). Os dados de cada pessoa ficam só no seu aparelho.
